# Pre-mortem (before any schema or infrastructure change)
Source: Gary Klein, Harvard Business Review, September 2007.

Answer four prompts before building:
1. What is the textbook default approach here?
2. It is six months later and this failed. What broke?
3. What is the smaller approach that uses primitives already in the stack?
4. What is the one judgment call that decides this, and who makes it?

Write the answers in the pull request or the changelog. If prompt 2 has no good answer, do not build yet.
