# labuladong reference

labuladong.online/en is a programming-education site with framework-thinking
algorithm tutorials and an AI-coding chapter. The point of framework thinking is
to reach for the canonical pattern behind a problem instead of improvising a
one-off, which produces cleaner and more predictable code.

How to use this skill: when a task touches one of the areas below, open the
matching page on the live site, read the relevant part, then apply it. Do not
paste the site's text into this project. Verify against the live page, because
pages are updated over time. Some content may require the site's paid tier.
