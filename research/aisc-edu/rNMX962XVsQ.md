## Flexural Members:  Is my Cb Factor Correct?
URL: https://www.youtube.com/watch?v=rNMX962XVsQ | Duration: 58:52 | Upload: NA | Tier: 2 | Watched: 2026-06-24
### Core Concept
This SSRC webinar by Todd Helwig (UT Austin) explains the Cb moment-gradient factor used to size laterally unbraced flexural members against lateral-torsional buckling (LTB). A beam under uniform moment is the base case Timoshenko derived [04:34], and Cb amplifies that base LTB curve for any real moment diagram, then the result is capped at the plastic moment Mp [08:11]. The talk teaches how to confirm a Cb value is correct, including back-calculating it from an eigenvalue buckling analysis as the ratio of the moment-gradient critical moment to the uniform-moment critical moment [10:13], and it covers cases the code equation does not cover cleanly: load position, singly symmetric sections, continuous beams with one-flange bracing, roof uplift, cantilevers, and girders during lifting.
### Spec References
The speaker cites the AISC specification Cb equation that has been in place since the mid-1990s, written brace-point to brace-point using M1 and M3 at the quarter points, M2 at centerline, and Mmax in the denominator [14:50]. He references AISC Section F2 for singly symmetric sections, noting the 13th-edition Section F2 modifier caused confusion and was removed so F2 now directs the user to a rational analysis [29:39]. The singly symmetric and special-case Cb expressions (one-flange bracing, gravity and uplift, the rho-top modifier 0.5 + 2(rho_top)^2 capped at 3) now live in the AISC Commentary [25:33][40:27]. He also cites AASHTO's older moment-gradient form and Timoshenko's cantilever buckling equations, plus the SSRC Guide (Nethercot) curve fits for load position [20:58]. The session PDCH code stated aloud is 288874 [00:30].
### Technical Details
The conventional Cb equation gives 1.0 for uniform moment, about 1.32 for a midspan point load with no intermediate bracing (published 1.35), and about 1.14 for a uniform load (published 1.12) [16:52]. It is unconservative only for a fixed-fixed beam with a midspan point load, a rare case [17:23]. Load position matters: top-flange loading lowers Cb, bottom-flange loading raises it, handled by multiplying Cb by 1.4 raised to the 2Y/H power, where H is flange-centroid depth and Y is positive below mid-height [20:58]. Top-flange load can drop effective Cb from 1.35 to about 0.96 [19:56]. Singly symmetric sections use rho = Iyc/Iy; reverse curvature requires the 0.5 + 2(rho_top)^2 modifier and a check of both flanges as potentially critical [25:33][27:36]. Special cases give very large Cb (5.5 and 2.93 in worked examples) because the full twist-prevented length is the unbraced length [38:25][40:58].
### Fabrication Notes
This is a design-stability webinar with no shop fabrication, fit-up, or QC content. The only fabrication-adjacent item is the continuity-plate detail across the column panel zone used to provide warping restraint to a cantilever beam at the column face, which the speaker flags as a costly detail often skipped in favor of conservatively neglecting warping stiffness [45:06].
### Erection Notes
The strongest erection content is girder stability during lifting [45:36]. With a single crane, spreader beam, and beam clamps, no point along the girder reliably stops twist, so the recommended method defines the unbraced length as the total segment length and assigns Cb by pick-point location: Cb = 2 for a/L below 0.225, Cb = 6 between 0.225 and 0.3 (near quarter points), and Cb = 4 above 0.3, using the minimum cross section properties along the length [50:46][51:48]. Picking at midspan is explicitly warned against. Bridge girders 180 to 200 feet need the large Cb values [51:48]. Two-crane or dual-spreader picks spread the moment diagram and help, but pick points are not brace points so the same total-length Cb method still applies [54:53].
### Common Errors / Inspection Failures
The recurring engineering errors named are: trusting the code Cb as exact when it varies roughly 1.25 to 1.4 in reality [11:15]; ignoring top-flange load position when there is no intermediate bracing and no tipping restraint, which is unconservative [33:44]; missing that masonry or stacked loads whose centroid sits above the top flange can cause Cb to plummet [34:16]; and assuming full warping restraint at a cantilever-to-column face, where web distortion can drop capacity from 2.8 kips to about 2 kips [45:06]. There is no welding or bolting inspection-failure content in this talk.
### Bid / Cost Implications
Cost implications are indirect. Over-conservative Cb assumptions add steel weight and tonnage; the warping-restraint cantilever case is framed as a direct trade between an expensive continuity-plate panel-zone detail versus accepting a conservative lower capacity [45:06]. Correctly crediting moment gradient and tipping restraint lets an engineer avoid adding bracing or upsizing members. None of this changes fabrication or erection unit pricing directly, but it drives member sizes that flow into tonnage.
