## Night School 6, Session 4: Vertical Bracing Connections - Corner Connection Part 1

### Core Concept
William Thornton works one full wind/low-seismic corner bracing connection start to finish, an SD example out of the AISC 14th edition Manual using the uniform force method (UFM) [02:07][03:44]. The key teaching point is that a single brace-to-corner connection is really four connections, each with its own limit-state stack: brace-to-gusset, gusset-to-column, gusset-to-beam, and beam-to-column [02:40]. The design sequence starts at the brace-to-gusset interface because that sets the gusset geometry, then walks the forces through each interface [05:16][77:31]. Many limit states repeat across the four interfaces, so once a check is shown it is skipped on later interfaces [03:11].

### Technical Details
Brace is a WT6x22.5 (A992 Gr 50), brace force plus or minus 75 kip, brace slope 43.6 degrees, UFM angle from vertical 46.4 degrees, gusset is a 3/8 inch plate A36 [03:44][04:14][13:00]. Eight A325 bolts, 3/4 inch diameter, threads excluded, standard 13/16 holes, 3 inch spacing, single-shear ASD value 11.9 kip each so 8 x 11.9 = 95.2 kip > 75 [05:16][05:46][06:16]. Whitmore section length 15.9 inches spread at 30 degrees each side, buckling K = 0.5, KL/r = 41, Fcr/Omega = 19.7 ksi giving 83 kip > 75 [25:31][26:31][27:06][29:06]. UFM geometry: beta-bar 8.5 inches (centered on the 16-7/8 inch gusset edge), ideal alpha 11.5 inches, but the 20 inch weld forces alpha-bar = 10.5 inches; the ideal value must be used in r = 24.2 or the forces will not close [31:43][33:20][33:50]. Resulting interface forces: Vb 25.4, Hb shear 35.6, Mb 25.4 kip-in, Vc 26.3, Hc 18.8 kip [34:20][34:51][35:23].

### Fabrication Notes
The gusset is a 3/8 inch A36 plate; double angles are 4x4x3/8 Gr 36 with horizontal short slots in the outstanding leg and 1-1/4 inch edge distance [04:14]. Minimum fillet weld for 3/8 inch plate or 3/8 inch angle is 1/4 inch, and every weld in the example is checked against that minimum and against the gusset base-metal shear-rupture T-min (gusset-to-beam T-min works out to 0.101 inch < 3/8) [58:22][65:45][59:28]. The 20 inch horizontal gusset-to-beam weld length is prescribed up front [03:44]. Holes are standard 3/4 inch (13/16 nominal) unless noted; net-section and shear-lag effects from the WT stem being unconnected drive the U = 0.874 reduction [04:14][08:22][08:53].

### Erection Notes
This is shop-detailed connection design, so explicit field/crane/rigging procedure is light. The practical erection-driven guidance: use the same beam depth on both sides of the column to avoid eccentricities on transfer forces, and use decent-size beams and columns because a brace node-connected in the analysis model may carry 400 kip the beam never "sees," making a tiny beam impossible to connect without doubler plates and stiffeners [76:31][77:01][77:31]. The 1/2 inch setback at the brace and the gusset-to-framing fit-up dimensions are fixed by the UFM geometry [33:20].

### Common Errors / Inspection Failures
Block shear of the WT and of the gusset is the most-emphasized failure mode, with separate tear-out paths for shear and for the axial component [10:58][51:03][52:06]. Bolt capacity is wrong if only single shear is checked: five limit states apply per bolt (bolt shear, bearing on main material, bearing on connection material, tear-out on main, tear-out on connection), take the least of the five for each bolt and sum [18:41][22:25][49:13]. A recurring engineer error is picking a brace member without regard to how it connects, ignoring net-section and shear-lag loss [07:20][77:31]. Using alpha-bar instead of ideal alpha in the UFM r-term makes the forces fail to balance [33:50]. Block shear of the beam is NOT checked for the vertical component because the beam is not coped and there is no recognized failure mode for ripping out the top flange [73:58].

### Bid / Cost Implications
Thornton answers a direct cost question: total engineering hours for one connection like this, from receiving loads to issuing a design sheet, runs about an hour, sometimes 20 minutes if connection pictures can be reused from prior jobs [78:35][80:09][81:11]. The calculations themselves run fast with in-house software, but data input is about 10 minutes and drawing/checking dominate the rest; AutoCAD pictures are not auto-generated from the calc [80:09]. Anyone doing these professionally needs a spreadsheet or hard-coded program; doing more than a couple by hand is uneconomic [79:07][81:11]. Economy levers when a connection will not work: change the force distribution (special-case Delta-Vb), enlarge a too-compact gusset, or upsize the beam/column [75:30][76:01].
