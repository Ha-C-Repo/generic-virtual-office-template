# TEMPLATE: Explainer Video
## Pattern — do not copy content, reuse structure only

---

## WHAT AN EXPLAINER DOES

An explainer answers: "What is this, who is it for, and why should I care?"
It is the most utilitarian video type — clarity above all. If a viewer
finishes confused, the explainer failed regardless of production value.

**The test for every sentence of VO:** Could a new hire on their first day
repeat this back accurately? If not, simplify.

---

## EXPLAINER TYPES — CHOOSE ONE

| Type | When | Visual Approach |
|---|---|---|
| **Concept Explainer** | Introducing an idea, process, or category | Abstract/metaphorical — diagrams, environments, b-roll |
| **Product Explainer** | How a product works step by step | Product in use, UI, result-focused |
| **Service Explainer** | What a company does and for whom | People in context, process b-roll |
| **Problem/Solution** | Reframing a pain point with a solution | Contrast structure — pain then relief |
| **"How It Works"** | 3-step or multi-step process | Sequential clips: step 1, step 2, step 3 |

---

## STRUCTURE — 60-SECOND EXPLAINER (10 clips × 5-6s)

| Time | Beat | Content | Shot Type | Audio |
|---|---|---|---|---|
| 0:00-0:06 | HOOK QUESTION | Open with the problem as a question | Atmospheric or abstract | VO: "[Question that names the problem]" |
| 0:06-0:14 | THE PROBLEM | Show the pain state | 2 clips: person in problem context | VO: "[Problem description — 20 words]" |
| 0:14-0:22 | THE SOLUTION | Name the solution — what it is | 1-2 clips: product/service introduction | VO: "[Solution introduction — 20 words]" |
| 0:22-0:38 | HOW IT WORKS | 2-3 steps — each shown | 3 clips: one step per clip | VO: "[Step 1 / Step 2 / Step 3 — 15 words each]" |
| 0:38-0:48 | THE RESULT | What life looks like after | 2 clips: outcome, relief, success | VO: "[Outcome — 20 words]" |
| 0:48-0:55 | PROOF / CREDIBILITY | Social proof or credential | 1 clip: proof element or text card | VO: "[Proof statement — 15 words]" |
| 0:55-1:00 | CTA | One action | Brand card | VO: "[CTA — 8-10 words]" |

## EXPLAINER VISUAL RULES

**Clarity over aesthetics:** An explainer shot that is slightly boring but
crystal clear beats a beautiful shot that leaves the viewer wondering what
they're looking at.

**One idea per clip:** In an explainer, every clip has a job. If you cannot
describe the clip's job in one sentence, it does not belong.

**Step clips (How It Works):** Each step clip should show the BEGINNING of
the action, not the middle or end. The viewer needs to see the setup to
understand the payoff in the VO.

**Text on screen:** Explainers benefit from key terms appearing as text
overlays alongside the VO — but these are added in post, not generated by
Runway. Note text overlay locations in the shot list.

**Avoid:** Excessive stock-feeling b-roll. If the clip doesn't directly
illustrate the VO point it accompanies, cut it.

## RUNWAY WORKFLOW PLAN — 60s EXPLAINER

```
PHASE 1 — REFERENCES
  Product/Service reference → Gen-4 Image (defines the visual language)
  Environment reference → Gen-4 Image (defines the setting)

PHASE 2 — VIDEO GENERATION
  Text [Clip 01: hook environment] → Gen-4.5 Video (atmospheric, no character)
  Text [Clip 02: problem A — character] → Gen-4.5 Turbo (first frame = env ref)
  Text [Clip 03: problem B — character] → Gen-4.5 Turbo (first frame = Last Frame 02)
  Text [Clip 04: solution intro] → Gen-4.5 Turbo (first frame = product ref)
  Text [Clip 05: step 1] → Gen-4.5 Turbo (first frame = product ref)
  Text [Clip 06: step 2] → Gen-4.5 Turbo (first frame = Last Frame 05)
  Text [Clip 07: step 3] → Gen-4.5 Turbo (first frame = Last Frame 06)
  Text [Clip 08: result] → Gen-4.5 Turbo (first frame = env ref, happier context)
  Text [Clip 09: proof card] → Gen-4.5 Video (text/graphic card, minimal motion)
  Text [Clip 10: CTA card] → Gen-4.5 Video (brand card, minimal motion)

PHASE 3 — AUDIO
  Text [VO — 120 words approx] → Text to Speech
  Text [music: "clean corporate underscore, modern and approachable, builds gently"] → Text to SFX

PHASE 4 — ASSEMBLY
  Clips 01-10 → Stitch
  Stitch + TTS + SFX → Add Audio
```
